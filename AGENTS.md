# Project Instructions

## General
- This is a custom-built website.
- Preserve the existing architecture unless there is a strong reason to change it.
- Do not introduce frameworks or dependencies without asking first.
- Prefer semantic HTML, vanilla JavaScript, and reusable CSS.
- Keep desktop, tablet, and mobile behavior in mind with every change.

## Editing
- Read existing related files before changing code.
- Do not rewrite an entire file when a targeted edit will work.
- Preserve existing functionality unless the task explicitly changes it.
- If a change affects multiple files, identify them before editing.

## CSS
- Reuse existing design tokens and CSS variables.
- Avoid unnecessary inline styles.
- Keep responsive styles organized with the existing structure.
- Do not duplicate styles that already exist elsewhere.

## JavaScript
- Prefer small, understandable functions.
- Avoid adding libraries for functionality that can reasonably be handled with vanilla JavaScript.
- Check whether similar functionality already exists before creating new scripts.

## Accessibility
- Maintain keyboard usability.
- Use appropriate alt text.
- Maintain visible focus states.
- Use semantic elements and ARIA only when appropriate.

## Before finishing
- Check for broken links or obvious console errors.
- Check mobile behavior.
- Briefly explain which files were changed and why.
